What this course teaches

This course teaches professional software engineering while using AI as a development partner. It is not anti-AI, a prompt-engineering course, or a collection of tricks. It develops the habits required to review, validate, test, refactor, document, secure, operate, and maintain generated artifacts.

Application code

C#, Python, React, Angular, and SQL require intent, tests, architecture, and maintainable change.

Infrastructure code

Bicep, Terraform, YAML, Dockerfiles, and Kubernetes manifests carry blast radius, cost, security, and rollback consequences.

Engineering evidence

Reviews, tests, plans, documentation, observability, and production-readiness decisions turn plausible output into owned work.
